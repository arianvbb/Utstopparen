# ☑️ Utstopparen
This project is made strictly for fun and to further enhance my coding knowledge. This is my first time endulding in modular programming and it makes the process of debugging and testing 1000x easier. Something I will definetely be doing for my future projects.

## ❇️Features
- **OOP**: This program revolves around Object Oriented Programming which was the point, I needed some practice here and figured this project would be a good way to get it.
- **Fstream**: This was used to read from and actually write, this way the user can locally store the data and ensure a progression element in the game.
- **Modularity**: My first time making a modular script, this splits the code into sections which are easier to debug and it makes the source code a lot more organized.

#### This project was made entirely in C++ with these following libraries: iostream, fstream, string, random, chrono, vector and array.

## 🤔The Process 

This project is based on my father in law's dedication to the art of stuffing animals. The UI is based in Norwegian but the source code and documentation kept in English. This project was primarily done to improve at OOP and I also learnt modularity in programming. A lot of this was achieved through reading documentation and watching a few videos before trying myself to create something functional in C++ that actually compiles.

## 📚My takeaways

The biggest takeaway by far is that of modular programming, it's a total game changer and something I will carry with me and utilize for a lot of my projects down the line.

It's also refreshed me on certain aspects of coding and taught me things such as defining fstream to writing, reading or even trunc (resetting). 


## 🚀Running the project 

1. Install the entire project in a folder on your pc.
2. Make sure to have a code editor installed alongside compatibility to compile C++ code.
3. Run the main.cpp file in the src folder.
